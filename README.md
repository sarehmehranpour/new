# ربات واتساپ - WhatsApp Bot

ربات هوشمند واتساپ که شماره‌ها را از API دریافت می‌کند، بررسی می‌کند آیا در واتساپ ثبت‌نام کرده‌اند یا نه، مخاطبین را اضافه می‌کند و پیام می‌فرستد.

## 🚀 ویژگی‌ها

### ✅ قابلیت‌های اصلی
- **دریافت شماره‌ها از API**: پشتیبانی از فرمت‌های مختلف JSON
- **بررسی ثبت‌نام واتساپ**: تشخیص شماره‌هایی که در واتساپ ثبت‌نام نکرده‌اند
- **مدیریت مخاطبین**: اضافه کردن خودکار مخاطبین جدید با نام "کدیورز+شماره"
- **ارسال پیام**: ارسال پیام به شماره‌های معتبر
- **گزارش کامل**: ثبت تمام فعالیت‌ها و نتایج

### 📊 گزارش‌گیری
- **موفق**: شماره‌هایی که پیام به آنها ارسال شد
- **ثبت‌نام نکرده**: شماره‌هایی که در واتساپ ثبت‌نام نکرده‌اند
- **ناموفق**: شماره‌هایی که با خطا مواجه شدند

## ⚙️ تنظیمات

### 1. تنظیم API
فایل `whatsapp_bot.py` را باز کرده و تنظیمات API خود را وارد کنید:

```python
config = Config(
    api_url="https://your-api-endpoint.com/numbers",  # آدرس API شما
    api_key="your-api-key",  # کلید API شما
    default_message="سلام! این پیام از ربات واتساپ ارسال شده است.",
    default_timeout=15,
    wait_between_actions=3.0
)
```

### 2. فرمت API Response
API شما باید یکی از این فرمت‌ها را برگرداند:

**فرمت 1: آرایه ساده**
```json
[
    "+989123456789",
    "+989876543210"
]
```

**فرمت 2: آرایه با آبجکت**
```json
[
    {"phone": "+989123456789"},
    {"phone": "+989876543210"}
]
```

**فرمت 3: آبجکت با کلید numbers**
```json
{
    "numbers": [
        "+989123456789",
        "+989876543210"
    ]
}
```

### 3. پردازش خودکار
ربات به صورت خودکار:
1. شماره‌ها را از API دریافت می‌کند
2. هر شماره را بررسی می‌کند
3. مخاطبین جدید را اضافه می‌کند
4. پیام‌ها را ارسال می‌کند
5. نتایج را ثبت می‌کند

## ⚠️ نکات مهم

### 1. محدودیت‌های واتساپ
- واتساپ محدودیت‌هایی برای ارسال پیام انبوه دارد
- ممکن است در صورت ارسال زیاد، اکانت شما محدود شود
- توصیه می‌شود بین پیام‌ها تاخیر مناسب قرار دهید

### 2. امنیت
- کلید API خود را در کد قرار ندهید
- از متغیرهای محیطی استفاده کنید
- فایل‌های لاگ را در جای امنی نگهداری کنید

### 3. پایداری
- اینترنت پایدار داشته باشید
- مرورگر Chrome را به‌روز نگه دارید
- ChromeDriver را با نسخه Chrome هماهنگ کنید
